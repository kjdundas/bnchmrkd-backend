# The reference corpus

1,082,591 World Athletics competition results for 6,892 athletes, 1964–2026,
loaded into the `reference` schema. Public data about real, named athletes:
readable by any signed-in user, writable only by the ingest.

## Running it

    cd ingest
    cp .env.example .env        # paste the Supabase connection string in
    python ingest.py disciplines
    python ingest.py athletes
    python ingest.py results    # resumable — run until `status` says 35/35
    python ingest.py status

Resumable and idempotent per source file. Each file deletes its own rows
before reloading, so running twice gives the same database as running once.
It stops cleanly at 95 seconds because the shell it runs in has a two-minute
limit, and a bulk load that dies halfway is worse than one that never began.

## Files

    manifest.json      the 35 canonical source files and, for the two that
                       were excluded, which lineage won and why
    disciplines.csv    211 raw discipline strings -> 207 canonical events,
                       generated by canonicalise.py rather than typed
    marks.py           the mark parser — seven formats in one text column
    ingest.py          the loader

## The two things a reader should know

**Discipline means the event AND its implement.** Shot Put (5kg) is a
different `discipline_id` from Shot Put, and 110m Hurdles (91.4cm) from
110m Hurdles. This is what makes a comparison at fifteen honest without a
single age-group special case — and why `senior_id` exists, so a career can
still be followed across the specification change.

**Hand timing and oversized tracks are flags, not footnotes.** 11,108 marks
are hand-timed, worth roughly 0.24 s over a sprint; 5,019 were set on an
oversized track. `season_bests` excludes both. Wind is trickier: it is
recorded on about 60% of sprint rows, so known-illegal is excluded and
unknown is kept. The honest phrasing is "wind-legal where known".
